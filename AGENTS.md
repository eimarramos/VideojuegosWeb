# AGENTS.md

## Descripción del proyecto

- Lee el archivo `PRODUCT.md` para entender el producto que se va a desarrollar, sus características principales y su público objetivo.

## Reglas de arquitectura

- Lee el archivo `ARCHITECTURE.md` para entender la estructura del proyecto y cómo se organizan las diferentes capas.

## Tareas

- Lee el archivo `TASKS.md` para conocer las tareas específicas que se deben realizar para desarrollar el producto. Cada tarea tiene un resumen que describe lo que se debe hacer.

## Comandos

**Comandos para instalar dependencias**

```
pip install -r requirements.txt
```

**Comandos para ejecutar el proyecto**

```
python main.py
```

**Comandos para ejecutar pruebas**

```
pytest tests/
```

## Validación

- Asegúrate de que cada tarea pasa todos los casos de prueba definidos en el proyecto.
