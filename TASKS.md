## TASKS

### Task 1: Página de inicio

**Resumen**: Crear una página de inicio atractiva que presente la página web de videojuegos y sus características principales.

### Task 2: Lista de Videojuegos

**Resumen**: Implementar una página que muestre una lista de videojuegos con sus reseñas y valoraciones.

### Task 3: Búsqueda y Filtrado

**Resumen**: Agregar funcionalidades de búsqueda y filtrado para que los usuarios puedan encontrar videojuegos por género, plataforma y popularidad.

### Task 4: Detalles del Videojuego

**Resumen**: Crear una página de detalles para cada videojuego que muestre información más detallada, incluyendo reseñas completas y valoraciones de los usuarios.

### Task 5: Usuarios y Autenticación

**Resumen**: Implementar un sistema de autenticación para que los usuarios puedan registrarse, iniciar sesión y dejar sus propias reseñas y valoraciones.
